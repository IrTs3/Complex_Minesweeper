================================================================
　复数扫雷  Complex Minesweeper  ·  macOS 版使用说明
================================================================

【规则】
  一个把"雷"扩展成复数的扫雷：雷有四种 —— +1、-1、+i、-i，
  格子上的数字是周围所有雷的复数和：
  纯实和带正负号显示蓝色（+2 / -2），纯虚和显示绿色（+i / -3i），
  实虚混合显示这个和的模长、紫色（√2 / √5）；
  实部与虚部会互相抵消，完全抵消时显示黄色 0——
  黄 0 说明周围有雷只是恰好抵消，不会连锁展开，别当安全区。

【怎么玩】
  1. 把 ComplexMinesweeper.app 拖进"应用程序"文件夹（或放桌面也行）
  2. 首次打开：在 App 上【右键 → 打开】，再点一次"打开"
     （本包没有苹果开发者签名，系统会拦一下，只需这一次）

     若提示"已损坏，无法打开"，打开"终端"执行：
         xattr -dr com.apple.quarantine /Applications/ComplexMinesweeper.app
     路径改成你实际存放的位置即可。

【系统要求】
  · Apple Silicon 芯片（M1/M2/M3/M4…）的 Mac
  · macOS 13.0 或更高版本

【基本操作】
  左键单击        翻开格子
  右键单击        弹出标记菜单（+1 / -1 / +i / -i / 清除）
  数字键 1~5      鼠标悬停在盖着的格子上时直接标记（5 = 清除）
  F1 / F2         打开或关闭游戏说明 / 重开当前局（局中会先弹确认）
  F3 / F4 / F5    直接切到 9x9 / 16x16 / 24x16（局中会先弹确认）
  标题栏 9x9 等   切换难度；CUSTOM 可自定义行列与雷数
  SEED            复制 / 保存 / 载入"种子"，可以分享同一局
  齿轮按钮        设置：换背景图、自定义四种标记与空白格的字符或图标、
                  改格子颜色、双击开格行为与判定毫秒、
                  装饰星光的密度与大小（网页端与桌面端同一套滑块；
                  密度单位是「每 100×100 像素多少颗」，滑块下面会显示
                  按当前窗口面积换算出的实际颗数与上限；切难度后颗数会跟着重算。
                  拉到 0 就是彻底关掉这层装饰）
                  ANIM FX 动效开关（目前仅网页端）：开格波前、标记弹入、
                  雷数翻牌、终局雷区显形等装饰动效的总闸；关掉后全部即时
                  呈现，系统开了「减少动态」时也会被强制关闭。
  顶栏滑条        调整背景图透明度（在标题栏/顶栏上，不在右下角）

【计时】
  第一次翻格之后才开始走表；切窗口或打开任何面板会自动暂停，
  回到棋盘继续。显示精度 0.1 秒。

【怎么算赢】两种方式任选其一
  · 把所有安全格子翻开
  · 或者把所有雷都按正确类型标记出来（不必翻开安全格）

  标题栏的 ±1 / ±i 两枚芯片实时显示实轴 / 虚轴各自
  "还有几颗没被正确标记"（可在表头勾选隐藏计数）。
  提示相同的一团雷允许整体取反（+1↔-1、+i↔-i），统计上一致就算对。
  两种口径均要求标记总数恰好等于雷数，多标或少标均不判胜。

【设置存在哪】
  游戏内设置（背景图、标记图标、格子颜色）默认保存在：
      ~/Library/Application Support/ComplexMinesweeper/
  其中 settings.ini 是纯文本，可以直接查看与修改。
  注意：设置保存在系统目录而不是 .app 内部，因此把整个 .app
  拷到别的 Mac，外观设置【不会】跟着走，需手动拷 settings.ini
  到新机器的同一路径。首次从旧版升级会自动迁移一次原有设置。
  若该目录不可写，会自动改用：
      ~/.complex_minesweeper/



  祝玩得开心！
