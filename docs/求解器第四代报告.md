## 一、一句话总结

复数口径的求解器从「Hard 17.4%、被经典口径碾压 66 倍差距」提升到「Hard 67.3%、与经典口径统计不可区分」，核心手段是让 DP 分量输出**按雷数 profile 分层的精确权重**并接入全局概率推理；全部结论经过暴力枚举 oracle 逐分量对拍（0 不一致）、概率恒等式校验（0 违规）、同棋盘逐局配对 McNemar 检验三重验证。

## 二、起点：两个问题

第四代开工前，求解器有两个已知问题：

1. **DP 边际概率 2.24× 高估**（P3-B 遗留缺陷）。低树宽 DP（P1）不剪全局雷数上限，解集是超集，把它的边际概率直接当权重用会污染全局推理。10-24 试过「拿它扣吸收池」实测负收益已回退。正解是让 DP 自己输出分层权重——这就是本轮的 A1/A2。
2. **DP 长尾**：nv≈90 的巨型分量 DP 失败，DFS 烧 400 万节点后降级采样，最坏单局 21~22 秒。

红线（P3 教训）：不改任何见证/必开必雷语义；经典口径对照臂不动；budgetK 语义不动。

## 三、做了什么

| 步骤     | 内容                                                                             | 结果                             |
| ------ | ------------------------------------------------------------------------------ | ------------------------------ |
| C1     | DP 失败阶梯重试（宽度 8→10、工作量 8M→16M）                                                  | 机制保留；实测后期的长尾另有原因               |
| C2     | 三贪心消元序择优                                                                       | 与原 min-fill 逐字节相同，无害保险         |
| A1     | **分层 BucketDP**：消息从标量升级为「按 (nr,ni) profile 分层」的权重表，消元变量折 delta、二维卷积、pre/suf 回传 | 每分量输出与枚举 FULL 同构的精确 profile 计数 |
| A2     | 分层成功的分量升格 FULL，自动进 globalFilter / exactProbs                                   | 2.24× 边际高估就地修复                 |
| 宽 9 解锁 | stride 守卫 160k→400k、工作量 4M→40M、新增 600MB 总内存守卫、宽度门槛 ≤8→≤9                       | pool 类陷阱猜清零                    |

关键设计点：前向消息含本桶 delta、后向 M 表不含（边际/类型/回传时再折）——这样 `profCellTypes` 才能拿到**真实 per-profile 雷型**（+1 与 −1 同为实轴增量，折早了就分不出）；卷积不可逆，回传「排除第 j 个子消息」用前后缀卷积，不做除法。计数从 int 拓宽到 long double（DP 解数可达 5^40）。缺省开，`MS_LAYERED=0` 回旧路径；`MS_DP_ORACLE=1` 开对拍。

## 四、权威大样本：复数 vs 经典（同棋盘同首点逐局配对）

**样本**：Easy 5000 / Medium 3000 / Hard 1000，复数与经典共用同一批棋盘与首点。

| 难度              | 复数（本作）    | 经典（对照）    | 配对（复数胜/经典胜） | McNemar p | 结论         |
| --------------- | --------- | --------- | ----------- | --------- | ---------- |
| Easy 9×9×12     | **94.6%** | 93.2%     | 145 / 74    | <0.0001   | **复数显著更强** |
| Medium 16×16×40 | **87.8%** | 87.4%     | 134 / 123   | 0.53      | 统计平手       |
| Hard 24×16×72   | 67.3%     | **68.8%** | 117 / 132   | 0.38      | 统计平手       |

9000 局契约自检全绿：必开误爆 0、位置错标 0、跨轴错标 0。

### 详细解读

**「零猜」与「会猜」是两条完全不同的取胜路线。** 看零猜胜率（一局从头到尾纯推理、一次都不用猜）：经典 77.1 / 69.2 / 35.3%，复数只有 43.7 / 1.5 / 0.0%。这符合直觉——经典「这个格周围恰好 N 颗雷」的单条信息量严格强于复数的「实部 a 虚部 b」。**但一旦进入必须猜的局面，复数把差距全部追了回来**：被迫猜局占比复数接近 100%（Hard），靠的是精确到每格每雷型的边际概率把每一次猜的期望损失压到最小。最终胜率 Easy 反超、Medium/Hard 追平——旧结论「复数和线索严格弱于经典计数线索」应改写为：**纯推理弱、概率推理追平、Easy 反超**。

**McNemar 配对怎么读。** 只看两版胜负不同的局：Easy 上复数赢了 145 局而经典只从复数手里抢回 74 局，若两者实力相同，这种一边倒的概率是 2⁻¹⁰⁷ 量级——所以 Easy 的反超是实打实的。Medium 134:123、Hard 117:132 都在二项噪声内，正确的说法是「统计不可区分」，而不是「复数更强/更弱」。

**历史链条（Hard 复数口径）**：1.0%（10-23，P0 之前）→ 17.4%（第四代基线）→ 58.0%（宽 8 分层）→ 67.2%（宽 9 解锁，n=500）→ 67.3%（n=1000 确认）。四代里没有一代靠运气：每一代的配对检验都是一边倒。

## 五、迭代过程：每一步的配对数据（seed 20261024，n=500）

| 版本         | Medium | Hard  | 关键变化                                     |
| ---------- | ------ | ----- | ---------------------------------------- |
| 旧基线（P3 时代） | 65.0%  | 17.4% | DP 分量被关在全局概率耦合之外                         |
| + 分层（宽 8）  | 86.4%  | 58.0% | DP 分量升格 FULL 进全局卷积；McNemar 107-0 / 209-6 |
| + 宽 9 解锁   | 88.0%  | 67.2% | 回退分量 1742→4；McNemar 9-1 / 49-3           |

第二种子确认（seed 20261111，n=500）：Medium 63.8→87.0%（1-117）、Hard 16.6→56.6%（5-205）——**提升不依赖特定种子族**。

**为什么提升这么大？** 不是「排序微调」，是信息增量：DP 分量此前只能提供「分量内部的孤立边际」（且被 2.24× 污染），升级后它们的格子进入全局 (Rtot,Itot) 卷积，全局推理能对它们证明「必安全 / 必雷（含真型）」。直接证据是陷阱猜（被迫猜时最优格仍 ≥20% 含雷率的死亡级猜）的构成变化：基线 Hard 1004 次陷阱猜里 962 次发生在「有回退分量」的局面（只能按统计近似猜），分层后降到 278 次，宽 9 解锁后只剩 1 次。

**有趣的副产物**：宽 9 解锁后 DP 阶梯重试从 44 次归零——下法变好以后，那些 nv≈90 的巨型分量根本不再形成（棋盘开得更开、分量更小），降级分量三档全部归零。

## 六、怎么证明数据是真的

1. **oracle 暴力对拍（闸 1）**：用另一套完全独立的算法（DFS 枚举器，节点预算 ×64、无剪枝语义差）穷尽分量，逐 profile 对拍「每个 profile 的解数 / 每格含雷解数 / 每格雷型位掩码」。累计 **986 个分量（含宽 9）0 不一致**；另 1245 个解数超 2e7 的分量走标量交叉互证，同样 0 不一致。
2. **概率恒等式（闸 2）**：模型里每颗雷必落在「FULL 分量格 ∪ 吸收池」，所以全盘概率加总必须精确等于剩余雷数（P3-B 的 2.24× 正是这条被假权重破坏）。全部调用 0 违规、approx 回退 0。
3. **校准表（闸 3）**：猜格按预测概率分桶，实际踩雷率无系统性偏移（<2% 桶 887 次实际 0%）。
4. **契约自检常亮**：引擎每个「证明」动作都对着真实棋盘验证并计数——「必安全」开出雷、标「必雷」却没雷、轴型错，错一次亮一次红灯。全部 9000+ 局 0 次。
5. **确定性**：同 seed 重跑逐局胜负逐位一致；默认开关与环境变量开关的输出逐位相同。

**对照实验的隔离性**：Easy 没有 DP 分量，分层代码根本不执行，1000 局逐位一致——排除任何全局副作用；经典口径不经过分层代码，对照臂纯净。

## 八、容易误读的数字

- **理论存活上界**（exp(Σlog(1−P)/局数)）：它用「当时算出的 P」连乘，且有幸存者偏差。旧版 P 被 2.24× 污染时上界被人为压低（28.5% vs 实际 17.4% 的「贴线」是假象）；新版实际 67.3% 反超上界 51.0%——**这个量从低估方向失真，只能当「概率有没有算错」的烟雾报警器，不能当地板或天花板**。
- **DP 放弃原因 [2]=工作量 / [3]=fillScope**：宽 9 解锁后全部归零，不再是问题。
- **500 样本 vs 3000+ 样本**：500 样本时 Medium 88.0% vs 经典 87.4% 看着像「双超」，大样本下 Medium 只剩 +0.4（p=0.53）——**小样本的优势声明必须靠配对检验而不是裸胜率差**。

## 十、剩余空间与收官判定

**概率/证明维度已到理论面顶**：剩余陷阱猜全部是精确验证的真死局（Hard 229 / Medium 103 次），降级分量 0、池口径 1。再聪明的数学也变不出安全格。

**唯一剩余杠杆是策略层**（被迫猜时选哪格）：P 相近时按信息量选格属于 one-step lookahead 邻域（此前被排除），轻量版预期 Hard +1~3 点、封顶。

**参赛叙事素材**：四代迭代把复数口径从「被经典碾压 66 倍差距」做到「Easy 显著反超、Medium/Hard 追平经典」；两口径共用同一批棋盘逐局配对、三重 oracle 验证、契约自检常亮——「诚实求解器」本身就是作品差异点。
