### 2. 作品是什么（一句话）
「一个自己设计玩法的复数扫雷——雷是 ±1 和 ±i，格子上显示周围雷的复数之和（模长）：
能在浏览器里玩、也能装进 Mac/Windows，带精确到每格的含雷概率提示、可自定义的视觉与动效、
种子互通，外加一个 16 篇的算法可视化学习站。」

- 作品链接：https://cms-xdkyntv9few.qoder.zone （Qoder Sites 部署，公开访问）
- 桌面端安装包：dmg / zip（可选附，注意官方「原则上不接受本地文件」——以线上版为主）

### 3. 为什么做（问题或想法的来源）
- 玩法是自己想的：把复数搬进扫雷——四种雷 ±1/±i、数字读作周围雷复数之和的模长，
  「用数学直觉玩扫雷」；设计动机与读数规则见 docs/游戏玩法说明指引.txt；
- 想要一个「完全按自己审美长出来」的扫雷：默认扫雷太丑、自定义项太少；
- 想验证「只描述想法、不手写代码」能把一个项目推到什么深度——顺手把部署、
  备案、监控、安全审计这些「游戏之外」的事也全走了一遍；
- 顺带给自己的算法学习做了个可视化站（学习站模块）。

> **先例口径（重要）**：同类玩法已有先例（Yueqing-Chen 的 Complexweeper「复扫雷」，
> Zig+Win32 单机版，另有第三方网页移植，GitHub ~155 star）。本作品为独立撞车——
> 2026-10-07 起全程 Qoder 独立实现，与其零代码重叠。作品帖写法：
> ①绝不写「首创复数扫雷」，只说「我做了一个复数扫雷」；
> ②主动一句带过：「同类玩法此前已有 Complexweeper 等实现，本作品的差异点在于
> 精确概率求解（复数和场景远难于经典扫雷）、mac/win/web 三端、种子系统与动效自定义」；
> ③不提对方项目细节，不评价，不引战。

### 4. 怎么用（5 步以内，评委照着能打开）
1. 打开作品链接直接进入游戏（首次到访自动弹出玩法说明；参赛版默认 #66CCFF 纯色背景）；
2. 左键开格、右键/长按标雷，数字键 1-3 快速标记，F1 随时看玩法说明；
3. 点 SETUP 选难度（初级/中级/高级/自定义 3-24-99）；
4. 菜单里开 SEED 工具箱：粘贴一串种子，解码成 JSON 看盘面、编辑后重新编码导入；
5. 进阶可玩「概率提示」：看每格精确含雷概率再决定点哪。

## 二、过程叙事主线（可直接扩写成帖）

**一句话概括**：2026-10-07 到 10-27 的 21 天里，161 个提交、约 1.8 万行代码，
从一个想法到「桌面三平台安装包 + 备案域名 HTTPS 线上站 + 三轮安全审计全绿」。

| 阶段 | 日期 | 里程碑 | 「交给 Qoder 什么 / 自己改了什么」叙事点 |
|---|---|---|---|
| 起点 | 10.07–08 | 桌面端 C++/SFML v1.0.0 Beta | 描述玩法与像素风审美，Qoder 搭出核心棋盘与渲染 |
| 桌面打磨 | 10.08–10 | 设置面板自定义（背景/格色/标记字符与图片/空白格）、快捷键 | 连环 UX 审查逐条修；「恢复默认要全覆盖」等规则由实测拍板 |
| 上网页 | 10.11–14 | WASM 方案 → 改纯 TS/Canvas 重写 | 架构裁决（WASM 嫌重）后整端重写；与桌面端逐像素对齐 |
| 触屏适配 | 10.17 | 双指捏合缩放、长按标记、visualViewport 稳定化 | iOS Edge 真机实测反馈驱动，CDP 模拟不出的环境坑如实记录 |
| 上线 | 10.20–21 | HTTPS 三步走（443 + 80 收口 + HSTS）、密码闸门 | 安全加固全由审查驱动：cookie Secure、限流、目录 404 |
| 备案 | 10.20–26 | ICP + 公安备案下来，页脚挂警徽 | 备案等待期并行做了监控与备份 |
| 深水区 | 10.22–23 | 每格精确含雷概率（分层计数+二维卷积）、求解器统计 300 局 | 概率自检「暴力对照+统计复跑」，经典胜率≠上界的教训写进文档 |
| 星空 | 10.22–23 | 星光密度改「颗/100×100px」、流星雨五角星头 | 双端参数逐字对齐；CDP 调参回路截图 |
| 种子工具箱 | 10.26 | 双端种子↔JSON 编解码、密钥必填政策 | 中文输入法吞键连环 bug → 用户一句「直接重写」收口成单一实现 |
| 收官 | 10.27 | 第三轮全面安全审计：高危 0 中危 0，719 项测试全绿 | 低危加固四件当天修完部署 |

**三个最出彩的真实故事（挑一个展开写细节+截图）**：
1. **输入法文本框收口重写**：种子工具箱文本框在 macOS 中文输入法下连续出 5 个 bug
   （出框/光标/吞字符/Shift 多打/滚轮反向），逐个打补丁后按用户意见收口成
   单一实现（统一 seedFieldKey 输入入口 + drawSeedFieldBox 绘制），整个 bug 类消失。
   → 展示「人发现 bug、AI 修不完时，人裁决换架构」的协作范式。
2. **X-Real-IP 信任链排查**：怀疑限流可被伪造 IP 绕过 → 逐层审到 nginx 三处
   proxy_set_header 实测排除。→ 展示安全审计不是走过场，719 项测试、46 项不变量。
3. **备案期间不闲着**：ICP 等待的两周里把 Healthchecks 九项死人开关、两层备份
   （服务器 28 份 + Mac 每小时异地 1000 份）搭完。→ 展示「项目 ≠ 只有代码」。
