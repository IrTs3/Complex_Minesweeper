#复数扫雷#（标题：特大号，墨色kInk，字距加宽，居中） #游戏规则#（小号，淡kInkSoft，居中，同排跟在主标题后）

#一、棋盘与目标#（节标题：中号偏大，深墨，字距加宽，行尾画一条1px浅灰横线，段后空24px）
1. 棋盘下藏着四种雷：#+1#（蓝kRealMine，大一号）、#-1#（蓝，大一号）、#+i#（绿kImagMine，大一号）、#-i#（绿，大一号），数量大致各四分之一。
2. 难度三档：#新手 9x9 十二雷#（中号，墨）、#中级 16x16 四十雷#（中号，墨）、#高级 24x16 七十二雷#（中号，墨）。另有 CUSTOM 自定义，行列雷数任选，还能指定实雷与虚雷的配比。
3. 胜利二选一：#翻开全部安全格#（墨，大一号）（雷怎么标都行）；或#把每一颗雷都标成正确类型#（墨，大一号）（不多不少）。

#二、数字怎么读#（节标题：同上）#（本游戏的核心）#（小号，淡）
翻开一格，显示的是它周围八格里所有雷的复数之和。
1. 和是纯实数：直接显示并带正负号，#蓝色#（"蓝色"两字本身涂kRealMine，自我示范），如 #+2#（蓝）、#-2#（蓝）。
2. 和是纯虚数：#绿色#（"绿色"涂kImagMine），如 #+i#（绿）、#-3i#（绿）。
3. 和是实虚混合：显示这个和的模长，也就是长度，#紫色#（"紫色"涂kMixHint），如 #√2#（紫）、#√5#（紫）。
4. 和恰好抵消为零：#黄色 0#（这个 0 和"黄色"二字都用kZeroHint，#EFE430；和"周围没有雷"的空格区分——真空格没有数字）。
#例一#（行首小标签：中号深墨）：周围藏 +1、+1、-1，净和 +1，这格显示 #+1#（蓝，大一号）。
#例二#（同例一）：周围藏 +1、+i，净和 1+i，长度 √2，这格显示 #√2#（紫，大一号）。
#例三#（同例一）：周围藏 +1、-1，完全抵消，这格显示 #0#（黄kZeroHint，大一号）。
#要点#（行首小标签：红kBadMark）：混合提示只给长度、不给方向。同样是 √5，和可能是 2+i，也可能是 1+2i，还可能是它们的相反数。你要从一片数字里联立解出每颗雷的类型，这就是本游戏的难点与乐趣。

#三、与经典扫雷最大的三个不同#（节标题）#（先看这里）#（小号，淡）
1. #数字会抵消#（中号，墨，大一号）：提示不是雷数。显示 +1 的格子周围可能只有一颗雷，也可能有5颗（比如 +1、+1、-1,+i,-i）。
2. #黄色 0 不代表周围没雷#（红kBadMark，大一号）：它只说明净和为零，一定有雷，可能是藏着 +1 与 -1、或 +i 与 -i 各一对。而且 #0 不会自动连锁展开#（红，大一号），每一格都要你自己点。把 0 当安全区是#新手第一大死法#（红）；正确用法是把 0 当强线索：它的八个邻居里的雷必须正好配成抵消对。
3. #赢法不止一种#（墨，大一号）：不翻开所有格子、把全部雷按正确类型标满（一颗不多一颗不少），同样获胜（#如果你足够厉害#（小号，淡，俏皮语气））。

#四、操作说明#（节标题）
· #左键#（中号，墨，大一号）点击未翻开的格子：翻开。#第一次点击永远安全#（蓝kRealMine）（布雷发生在首点之后，首点及其周围八格保证无雷）。
· #右键#（中号，墨，大一号）：弹出标记菜单，五项：+1、-1、+i、-i、清除。
· #数字键 1 到 5#（中号，墨，大一号）：鼠标悬在盖着的格子上直接标记。1 是 +1，2 是 -1，3 是 +i，4 是 -i，5 是清除。
· #中键，或快速双击已翻开的数字格#（中号，墨，大一号）：批量开格。当这格周围每一颗雷都被你标对类型时，一键翻开其余邻居；没标对则什么都不会发生，不惩罚、不误爆（#除非开了BOOM#（小号，淡））。
· 表头 EASY、MEDIUM、HARD、CUSTOM 切换难度或开自定义面板；齿轮是设置。（本整行：小号，淡）
· 计时只在你看着棋盘时走：切窗口或打开任何菜单会自动暂停（#TIME PAUSED#（小号，淡））。

#五、胜负判定#（节标题）
· 踩到雷：#BOOM#（红kBadMark，大号，字距加宽），失败，全图揭晓。
· #路径一#（行首小标签：绿kImagMine）：翻开全部安全格即获胜；这时候雷怎么标、标不标都随你，甚至标错也不算错。
· #路径二#（行首小标签：绿kImagMine）：把每一颗雷都标成正确类型即获胜；但必须不多不少——在安全格上多插旗会破坏判胜，雷漏标一颗也不算。
· #友好规则，翻转也算对#（蓝kRealMine，大一号）：若某片区域从所有数字上根本分辨不出 +1 与 -1 谁是谁，那么把这片区域的标记整体对调（+1 与 -1 互换，或 +i 与 -i 互换）同样判胜，与全部提示统计一致就是解。但#跨轴不行#（红）：实轴的雷标成虚轴一定算错（#除非没有其他依赖的雷#（小号，淡））。
· 表头计数 #±1 xN#（蓝）、#±i xM#（绿） 表示两个轴各自还有多少颗没被正确标记，收官时非常有用；硬核玩家可勾选隐藏计数。

#六、进阶玩法#（节标题）
· #模长模式#（中号，墨，大一号）：勾选表头"总是显示模长"后，所有非零提示一律只给模长，不分正负、不分实虚；判胜标准同步变为：标记恰好盖住每一颗雷，且每格标记之和的模长与提示吻合，不再要求类型逐一对应。#更难，也更纯粹#（小号，淡，收尾腔）。
· #种子分享#（中号，墨，大一号）：菜单 COPY SEED 复制本局参数，朋友在 LOAD SEED 贴入，玩到的就是与你完全相同的雷，连首点位置都包含在内。SAVE PROGRESS 复制的是当前进度，别人可以从你的半局接着玩。格式不符会提示 #BAD SEED#（红，小号）。菜单最后一项 #SEED TOOLBOX#（中号）弹出「种子工具箱」：种子串与明文 JSON 互转，密钥必填（留空直接拒绝——不代读游戏内置密钥）；编解码判定与游戏端同口径，编码遇到自相矛盾的 JSON 会给 ⚠ 警告但照样给串。
· #外观#（中号，墨，大一号）：设置里可换背景图、自定义四种标记的字符或图片——自定义标记也是无障碍路径，辨色吃力的玩家可以把四个标记换成形状迥异的字符或图片，不靠颜色也能玩；所有设置即时保存，RESTORE ALL 一键回默认。

效果词表（就这几种，全是你 Renderer 里现成的）：
颜色：蓝=kRealMine，绿=kImagMine，紫=kMixHint，黄=kZeroHint（#EFE430，抵消为零但有雷），红=kBadMark，墨=kInk，淡=kInkSoft。如果你代码里这些常量名不是这个（比如蓝色另有其名），对齐 drawHint 画数字时用的同色即可，效果等价。
字号：标题／大号／中号／正文／小号，五档，一档约乘 1.15，或直接写死五档像素。
字距加宽：逐字排版时每字 advance 加 1px。
分隔线、行首圆点：RectangleShape 画，不依赖字体；列表项的 · 建议渲染成 4px 圆点，颜色随该行第一个片段的颜色。
大一号：真粗体 SFML 单字体做不了，全部用"字号升一档＋深墨"代替——这也是我通篇没写"加粗"的原因。
