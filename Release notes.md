## 🧪 Beta Release

Thank you for participating in this beta test! This version is still under active development and may contain instability or known issues. It is intended for testing purposes only and is not recommended for production use.

### 📦 Installation Instructions

1. Download the `.dmg` or `.zip` file (extract if using `.zip`).
2. Double-click to open, then drag the application into the `Applications` folder.
3. If you see an "Unable to verify developer" warning on first launch, go to `System Settings → Privacy & Security` to allow it, or follow the instructions in `使用说明.txt` to run it via Terminal.

For Windows users:

1. Download the `.zip` file and extract it.
2. Double-click the `.exe` file to run.

### 🐛 Issue Reporting

If you encounter crashes, unexpected behavior, or other issues, please submit feedback via the **Issues** tab in this repository. Please include as much of the following information as possible:

- macOS or Windows version
- Steps to reproduce the issue
- Screenshots, screen recordings, or log files
